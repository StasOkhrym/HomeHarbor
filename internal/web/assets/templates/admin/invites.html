Signed invite · trusted companion

Create the invite on your Mac for a profile already present in signed configuration. Send the link and 8-digit code through separate channels.

admin invite --config /path/to/admin.toml

Run the admin CLI on your trusted companion. Replace /path/to/admin.toml with its configuration file for this deployment and choose the intended profile there. The link and code are output locally, not returned by this panel.

After the device submits its proof, approve locally using admin approve, then publish its addition using admin publish-snapshot. Use CLI help for the required flags. Never paste the code, passphrase or private key here.
