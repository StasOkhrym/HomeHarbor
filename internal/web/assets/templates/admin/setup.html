{{define "setup"}}

1. Prepare your trusted companion

Your passkey protects this panel. The separate signing key on your Mac authorizes LAN access.

admin init-root --config /path/to/admin.toml

Run the admin CLI on your trusted companion. Replace /path/to/admin.toml with its configuration file for this deployment. Create a root only if its signing key does not already exist. Never upload the private key or passphrase to this panel.

2. Enroll your gateway

Create a legacy gateway enrollment token, then use it with the Linux gateway. Private node keys stay on that node.

Create gateway token →

{{.Devices.Count}} enrolled devices. Registration is not confirmation of connectivity.

3. Review routes, DNS and access

Approve the intended LAN route and DNS settings. Add catalog services and access profiles, then review default-deny ACL.

Routes & DNSServicesAccess rules

These are saved control records, not signed network grants.

4. Publish your initial signed configuration

Prepare a manifest using config/initial-snapshot.example.toml. Review its exact devices, routes, services, profiles and ACL locally.

admin init-snapshot --config /path/to/admin.toml --manifest /path/to/initial-snapshot.toml

Replace both paths with the trusted companion's configuration and reviewed manifest for this deployment. This command is for revision 1 only. Later arbitrary topology edits are not implemented by the current companion CLI. Saving forms cannot publish them.
